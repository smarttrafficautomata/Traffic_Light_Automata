PROJECT OVERVIEW

Understanding Traffic Signals Through Automata

Traffic lights can be represented as a deterministic finite state machine where each signal represents a state and the timer determines the transition.

🔴

RED State

Vehicles must stop while the signal remains red.

🟢

GREEN State

Vehicles are allowed to move through the intersection.

🟡

YELLOW State

Vehicles prepare to stop before the signal turns red.

AUTOMATA CONCEPTS

How This Project Uses FSM

States

RED, GREEN and YELLOW represent the finite states of the automaton.

Input

Timer values act as the input condition that triggers state transitions.

Transition

The transition function determines the next state of the traffic signal.

Deterministic Behaviour

Every state follows a fixed transition, making the machine deterministic.

ABOUT THE PROJECT

Traffic Light Automata

This project demonstrates the application of Finite Automata in a real-world traffic control system. The traffic signal is modeled as a deterministic finite state machine.
