THEORY OF COMPUTATION

Automata Concepts Used

Finite States

The system contains three finite states: RED, GREEN and YELLOW.

State Transition

Each state changes according to a predefined timer.

Deterministic Behaviour

For every current state, the next state is uniquely determined.

Input / Timing

The timer acts as the transition condition for the automaton.

PROJECT INFORMATION

About This Project

Traffic Light Automata is a Theory of Computation project that demonstrates how a real-world traffic signal can be modeled using a finite state machine.

The project combines automata theory, state transitions, timers, traffic signal control and visual road simulation.
